# Character Selection Images (Square)

This folder contains **square** character portrait images used for the character selection grid panel.

## Image Specifications

- **Format**: PNG (preferably with transparency)
- **Size**: 512x512px or 600x600px (square)
- **Content**: Character portrait or bust
- **Aspect Ratio**: 1:1 (square)

## Naming Convention

All character images must follow this naming pattern:
- Use **lowercase letters only**
- Replace spaces with **underscores** (`_`)
- File extension must be **.png**

## Usage

These images are displayed in the character selection panel when building your team. They appear as circular avatars with the character's affinity color border.

## Note

This folder is separate from `assets/characters/` which contains full-body vertical images (861x1239) used for the team composition visual display.
